# СтепМаркет — интернет-магазин обуви

Учебный SPA-проект на React + Vite. Каталог товаров, карточка товара, оформление
заказа, управление заказами и роли. Бэкенда нет — данные берутся из mockData.json,
изменения хранятся в localStorage.

Вариант А (обувь). Чтобы переключиться на вариант Б, в src/App.jsx поменять
ACTIVE_VARIANT на "variantB".

## Стек

- React 18 (JavaScript, .jsx)
- Vite
- CSS
- localStorage вместо бэкенда

## Запуск

    npm install
    npm run dev

Открыть http://localhost:5173

Сборка:

    npm run build
    npm run preview

## Аккаунты для входа

Вход только по логину, пароля нет.

- client1 — клиент
- client2 — второй клиент
- manager1 — менеджер
- admin1 — администратор

Гость тоже может смотреть каталог и карточку товара, но без фильтров,
сортировки и оформления заказа.

## Функционал

Каталог:
- карточки в 3 колонки: фото, описание, цена;
- если у товара пустой image или картинка не загрузилась — подставляется
  /picture.png;
- остаток считается по всем вариантам. Больше 5 — «много», меньше или равно 5 —
  «мало», меньше или равно 3 — карточка подсвечивается красным;
- скидка 25% даётся товару, по которому не было заказов в прошлом календарном
  месяце. Старая цена зачёркнута;
- поиск по названию и описанию, фильтр по категориям (первый пункт «Все
  категории»), сортировка по итоговой цене вверх/вниз. Всё работает
  одновременно в реальном времени.

Карточка товара:
- открывается по клику на карточку в каталоге;
- недоступные варианты (остаток 0) заблокированы;
- количество проверяется: нельзя ввести 0, минус, буквы или больше остатка.
  Ошибка выводится текстом под полем;
- можно добавить несколько позиций в черновик, убрать позицию, отменить заказ
  целиком или подтвердить;
- при подтверждении создаётся заказ с сегодняшней датой, остатки списываются,
  всё сохраняется в localStorage.

Заказы (только менеджер и админ):
- список заказов с составом и итоговой суммой;
- можно добавить новый заказ через поиск товара по каталогу;
- можно удалить заказ целиком — остатки вернутся в каталог;
- админу дополнительно доступны изменение даты заказа и удаление отдельной
  позиции (с возвратом остатка). У менеджера этих кнопок нет.

Общее:
- шапка с логотипом, названием компании, ФИО и ролью пользователя, кнопками
  «Заказы» и «Войти/Выйти»;
- у каждого экрана своя кнопка «Назад»;
- document.title меняется под текущий экран;
- иконка вкладки подключена в index.html.

Работа с данными и расчёты вынесены в отдельные модули (storage.js,
catalogLogic.js). Это чтобы потом заменить localStorage на fetch к Django API и
не переписывать экраны.

## Картинки

Лежат в public/:

    public/
    ├── logo.png
    ├── favicon.ico
    ├── picture.png
    └── images/
        ├── airrun.png
        ├── nordic_boot.png
        └── urban_trail.png

Пути совпадают с полями image в mockData.json. Для товаров с пустым image
картинку не кладу — сработает заглушка /picture.png.

## localStorage

Ключ: pr_de_state_variantA. Там хранятся products и orders.

Сбросить состояние к исходному: DevTools → Application → Local Storage → удалить
ключ → F5.

## Про даты и скидку

Скидка считается от реальной текущей даты. В mockData.json два заказа: один за
октябрь 2026, второй за сентябрь 2026. Если запускать в другой месяц, даты в
JSON надо поправить, иначе скидка будет считаться не так, как задумано. После
правки JSON нужно очистить localStorage, иначе Vite подтянет старые данные.
